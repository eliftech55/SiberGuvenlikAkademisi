# Cyber Academy Quest

A full HTML5 educational browser game built with Phaser.js and Supabase.

## Setup

1.  **Install dependencies:**
    ```bash
    npm install
    ```

2.  **Supabase Setup:**
    - Create a project on Supabase.
    - Run the SQL schema in `supabase_schema.sql` in the Supabase SQL Editor.
    - Create a `.env` file from `.env.example` and add your `VITE_SUPABASE_ANON_KEY`.
    - Enable **Anonymous Auth** in Supabase (Authentication -> Providers -> Anonymous).

3.  **Run locally:**
    ```bash
    npm run dev
    ```

4.  **Build for production:**
    ```bash
    npm run build
    ```

## Features

- **Avatar Creation:** Choose a codename and avatar.
- **7 Mini-Games:** Specialized missions to earn badges.
- **Cloud Sync:** Progress saved to Supabase with offline support.
- **Modular Architecture:** Easy to add new missions.

## Deployment

Hosted on GitHub Pages by deploying the `dist` folder generated by `npm run build`.
